# Code standards

1. Keep it simple, do not overcomplicate.
2. Ask for one small change at a time for very small incremental steps.
3. Test at every point and run npm run check after every change.
4. Commit at every point.
5. Go back as needed and try again.
6. Comments only when necessary.
7. Be concise: a short README and no emojis.
8. IMPORTANT: avoid overly defensive code. Handle exceptions only when necessary.
9. Use uv: ALWAYS `uv run`, NEVER `python3`.
10. TypeScript: strict mode, never `any`.
